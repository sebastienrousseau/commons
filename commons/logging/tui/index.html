Opt-in terminal dashboard for live observability metrics. Opt-in terminal dashboard for live observability metrics.

Set RLG_TUI=1 to spawn a background render thread that paints a non-clobbering sparkline dashboard at ~60 FPS. Enable the logging-tui feature for automatic terminal size detection; otherwise falls back to 80x24.
