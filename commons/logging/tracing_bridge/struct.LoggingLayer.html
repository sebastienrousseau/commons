Struct LoggingLayer 

Source 
pub struct LoggingLayer { /* private fields */ }
Available on crate features logging-tracing-layer and logging only.
Expand description

A composable [tracing_subscriber::Layer] that routes events into the logging engine.

This allows the logging system to be used alongside other tracing layers in a tracing_subscriber::Registry stack.

§Example

ⓘ
use tracing_subscriber::prelude::*;
use commons::logging::tracing_bridge::LoggingLayer;

tracing_subscriber::registry()
    .with(LoggingLayer::new())
    .init();
