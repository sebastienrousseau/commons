Near-lock-free ingestion engine backed by a bounded ring buffer. Near-lock-free ingestion engine backed by a bounded ring buffer.

The global ENGINE accepts LogEvents via LockFreeEngine::ingest() using only atomic operations. A dedicated background thread drains events in batches of 64 and writes them through PlatformSink.

The Mutex is never locked on the hot path. It exists solely for shutdown() to join the flusher thread.
