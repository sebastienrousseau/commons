Portable monotonic counters for targets without 64-bit atomics. A monotonic u64 counter that works without 64-bit atomics.

std::sync::atomic::AtomicU64 does not exist on targets that lack 64-bit atomic instructions – powerpc-unknown-linux-gnu among them, where importing it fails with E0432: unresolved import. That broke every downstream build for those targets.

Each counter in this crate is a monotonically increasing sequence number read through fetch_add, so a mutex-backed fallback is behaviourally identical. Only the contention profile differs, and these are incremented once per generated identifier rather than in a hot loop.

The two definitions are written out rather than wrapped in an inner module, because a re-export would be either an unreachable pub or a redundant pub(crate) – both denied by this crate’s lints.
